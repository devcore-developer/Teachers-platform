# النسخ الاحتياطي والاستعادة — منصة منارة قرطبة

> مكتوب بعد التحقق الفعلي: سكربتا النسخ والتحقق نُفِّذا بنجاح على قاعدة
> بيانات حقيقية داخل بيئة التطوير (نسخة + تحقق تكامل + تقليم استبقاء).
> لا يُدّعى هنا أن أي نسخة احتياطية "تعمل" قبل أن يُختبر بهذا السكربت.

## 1. الأدوات الجاهزة (بدون أي اعتماديات جديدة)

| الأمر | الوظيفة |
|---|---|
| `bun run backup` | نسخة متسقة عبر `VACUUM INTO` من قاعدة SQLite — لا يقفل التطبيق ولا يعدّل الملف الأصلي، ويكتب بصمة SHA-256 بجانب النسخة |
| `bun run backup:verify -- <مسار النسخة>` | تحقق قراءة فقط: `integrity_check` + `foreign_key_check` + أعداد صفوف الجداول الأساسية |

- مصدر قاعدة البيانات: متغير `DATABASE_URL` (يجب أن يكون `file:...`).
  السكربت يرفض أي مزود غير SQLite ويطبع مسار المصدر الذي نُسخ فعليًا.
- مكان النسخ: `BACKUP_DIR` (الافتراضي `.data/backups/`) — **خارج مجلد
  قاعدة البيانات نفسه**، ومستثنى من git عبر `.gitignore`.
- الاستبقاء: `BACKUP_KEEP` (الافتراضي 14 نسخة) — الأقدم يُحذف تلقائيًا
  بعد نجاح النسخة الجديدة والتحقق منها.

## 2. إجراء النسخ اليدوي (دقيقة واحدة)

```bash
cd platform
bun run backup
bun run backup:verify -- .data/backups/<اسم-الملف>.sqlite
